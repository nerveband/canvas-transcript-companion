# Privacy Policy

Effective date: May 13, 2026

Canvas Transcript Companion does not collect, transmit, sell, rent, or share user data.

## What the extension does

Canvas Transcript Companion runs on supported Canvas LMS pages and Canvas Studio / Arc video frames. When a captioned video is available, it reads caption timing data in the browser so it can display a searchable transcript and let the user click transcript sentences to seek the video.

## Data handling

The extension processes transcript and caption data locally in the browser. It does not send transcript text, course page content, video metadata, browsing history, account information, or authentication information to any external server.

## Network access

The extension may read caption or transcript files that the Canvas video page already requests or exposes to the user. These requests are made from the browser to the same Canvas / Canvas Studio domains used by the course page.

## Storage

This version does not use Chrome extension storage for user data.

## Third parties

The extension does not use analytics, advertising, tracking pixels, remote code, or third-party telemetry services.

## Contact

For support or privacy questions, contact the extension publisher through the Chrome Web Store listing.
